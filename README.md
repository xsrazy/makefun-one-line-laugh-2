One funny line about a clingy phone that refuses to take the hint, written for the "One Line, One Laugh" bounty on make.fun.

## Run it

```bash
python3 main.py
```

The program writes the winning one-liner to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (default `/output`), as UTF-8 text with no trailing newline.
